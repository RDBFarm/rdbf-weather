# Working in this repository

Read `README.md` first: it holds this repository's rules (nothing estimated,
missing values left blank, all times Eastern, `weather_history.csv` and
`weather_summary.json` written only by the script).

## Committing and pushing

**Weather work here may be committed and pushed to `main` without asking.**
The owner, 2026-10-14, while the forecast scoring was being set up: "Right now
we are just looking at forecasting models to get a good idea of who to use in
the future. So you always have my permission to commit and push without
asking. No damage done at this point." Asked whether that covered weather work
generally: "yes add it for the weather related activities."

That covers finished work that has been run and checked, not skipping the
checks. It is about this repository's weather work only; it does not carry
over to `rdbf-app`, which has its own rules.
